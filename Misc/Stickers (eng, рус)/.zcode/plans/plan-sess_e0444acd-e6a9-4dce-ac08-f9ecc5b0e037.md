# План переименования 138 GIF-файлов по системе тегов

## Цель
Переименовать все файлы с русскими названиями в формат с двуязычными тегами для удобного поиска ассетов в монтаже.

## Требования к именованию (из примеров и ответов пользователя)

### Формат:
`[английские теги], [русские теги].gif`

**Примеры существующих:**
- `star, prize, звезда, награда.gif`
- `keyboard, typing, клавиатура, печать.gif`
- `lock, key, open, close, замок, ключ, открыть, закрыть.gif`
- `toiler paper, туалетная бумага, рулон, говно, shit, poop.gif`

### Правила:
1. **Количество тегов:** 4-6 тегов (компактно)
2. **Порядок:** сначала все английские теги, затем все русские
3. **Формат:** существительные, максимум глагол для действий
4. **Эмоциональная окраска:** добавлять по контексту (если гифка юморная/экспрессивная)
5. **Только буквы и пробелы:** никаких дефисов, слешей и спецсимволов (кроме запятых)
6. **Составные слова:** через пробел (например: "exclamation mark", "toilet paper")

## Процесс выполнения

### Этап 1: Анализ гифок (Phase 1 - Understanding)
1. Взять список из 138 файлов только на русском
2. Открыть каждую гифку через браузер для визуального анализа
3. Определить содержимое и подобрать ассоциативные теги по принципу:
   - Что изображено (объект/объекты)
   - Действие (если есть)
   - Контекст использования
   - Эмоциональная окраска (если применимо)

### Этап 2: Создание примеров для проверки (Phase 2 - Testing)
1. Выбрать 5-10 разнообразных файлов:
   - Простые объекты (например: "Лупа.gif")
   - Составные объекты (например: "Ключ с замком.gif")
   - Действия (например: "Отправить письмо.gif")
   - Специфические/юморные (например: "Джва скрипт.gif" - явно про JavaScript)
   
2. Создать копии этих файлов с новыми именами (не переименовывать оригиналы)
3. Показать пользователю для одобрения стиля

### Этап 3: Массовое переименование (Phase 3 - Implementation)
После одобрения примеров:
1. Удалить тестовые копии
2. Переименовать ВСЕ 138 файлов по утвержденной схеме
3. Создать git commit с сообщением типа "Rename sticker files with bilingual tags for search"

### Этап 4: Возможность отката
- **Git:** можно откатить через `git checkout .` или `git reset --hard HEAD~1`
- Пользователь сможет в любой момент откатить изменения

## Технические детали

### Инструменты:
- **Browser Use** для визуального анализа каждой гифки
- **Bash** для операций с файлами (cp для копий, mv для переименования)
- **Git** для commit и возможности отката

### Безопасность:
- Сначала создаются копии для проверки (не трогаем оригиналы)
- Git commit после финального переименования
- Всегда можно откатить через git

### Время выполнения:
- Визуальный анализ 138 гифок: ~20-30 минут (по 10-15 сек на файл)
- Создание 5-10 примеров: ~2 минуты
- Проверка пользователем: зависит от пользователя
- Массовое переименование: ~1-2 минуты
- Git commit: 10 секунд

**Общее время: ~25-35 минут + время на проверку пользователем**

## Что будет на выходе

После выполнения всех файлы будут иметь двуязычные теги для быстрого поиска:
- ✅ Поиск по английским ассоциациям (удобно для профессиональной терминологии)
- ✅ Поиск по русским ассоциациям (удобно для естественного языка)
- ✅ Множественные теги увеличивают вероятность найти нужный ассет
- ✅ Единообразный формат по всей коллекции
